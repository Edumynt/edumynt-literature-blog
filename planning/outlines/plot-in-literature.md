# Outline — Plot in Literature

## Working Title
Plot in Literature: Structure, Conflict, Examples, and How Stories Create Meaning

## Research Notes / Grounding
- Aristotle’s *Poetics* treats plot (*mythos*) as the arrangement of incidents and considers it central to tragedy.
- E. M. Forster’s classic distinction: “The king died and then the queen died” is story; “The king died and then the queen died of grief” is plot because it shows causality.
- Freytag’s pyramid is useful but too rigid if treated as universal; modern fiction often disrupts linear structure.
- Strong plot analysis should connect events to causality, conflict, character choice, structure, theme, and reader expectation.

## Purpose
Create a long-form Literature By Edumynt guide that explains plot as more than “what happens.” The post should teach readers how plot organizes events into meaningful cause-and-effect patterns.

## Audience
General literature readers, students, teachers, and serious beginners. In-depth but not exam-crammy.

## Structure
1. Introduction — plot as the architecture of story.
2. What Is Plot? — definition and distinction from story.
3. Plot vs Story vs Narrative — clarify related terms.
4. Why Plot Matters — causality, conflict, suspense, theme, character.
5. Basic Elements of Plot — exposition, inciting incident, rising action, climax, falling action, resolution.
6. Freytag’s Pyramid — useful model and limitations.
7. Types of Plot Structure — linear, non-linear, episodic, circular, parallel, frame narrative.
8. Plot and Conflict — external/internal conflict as engine.
9. Plot and Character — choices create consequences.
10. Plot and Theme — events become meaningful patterns.
11. Detailed Examples — Macbeth, Pride and Prejudice, The Great Gatsby, Things Fall Apart, The Odyssey.
12. Common Mistakes — plot summary vs plot analysis, treating structure as formula, ignoring causality.
13. How to Analyze Plot — practical method.
14. FAQ.
15. Conclusion.
